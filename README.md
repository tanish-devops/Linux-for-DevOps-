> Why Linux for DevOps?

Linux is foundational to modern DevOps and cloud infrastructure:

~90% of cloud servers run on Linux

Containers (e.g., Docker) rely on Linux kernel features (namespaces, cgroups)

CI/CD pipelines typically execute on Linux-based runners/agents

Most production environments are Linux-based

> Understanding Linux deeply enables:

Faster troubleshooting

Infrastructure automation

Security hardening

Better cloud architecture decisions
